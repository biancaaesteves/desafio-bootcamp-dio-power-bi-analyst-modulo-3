# desafio-bootcamp-dio-power-bi-analyst-modulo-3
Repositório do desafio do módulo 3 da formação Power BI Analyst (DIO), com foco na integração entre MySQL (Azure) e Power BI. O projeto contempla etapas de ETL, incluindo limpeza, tratamento e transformação dos dados, além da organização das tabelas para preparação de um modelo analítico eficiente.
